# Mesa de Decisão: Investimentos e Liquidez
1. Crie um repositório no GitHub e envie todo o conteúdo desta pasta (inclusive `.github`).
2. Settings > Pages > Deploy from branch > `main` / root.
3. Actions > "Atualizar notícias" > Run workflow (primeira carga). Depois roda sozinho em dias úteis.
4. Teste local: `python -m http.server` e abra http://localhost:8000
Os dados do usuário ficam só no navegador (localStorage). Use Dados e relatório > Baixar backup.
